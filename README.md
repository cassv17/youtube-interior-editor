# 영상 자동편집

유튜브 롱폼 영상의 **무음 구간 컷**과 **자막 달기**를 자동으로 해 주는 프로그램입니다.
브라우저 화면에서 결과를 확인하고 고친 뒤, 완성된 mp4(와 srt 자막 파일)로 내보냅니다.

- 모든 처리는 **이 컴퓨터 안에서만** 이뤄집니다. 영상은 인터넷으로 전송되지 않습니다.
  (설치할 때 음성인식 모델 파일만 한 번 내려받습니다.)
- **원본 영상은 절대 수정되지 않습니다.** 작업용 사본과 결과물은 이 폴더 안에 따로 만들어집니다.

---

## 1. 처음 한 번만: 설치

### 1-1. 미리 필요한 프로그램 2개

| 프로그램 | 확인 방법 | 없을 때 설치 방법 |
|---|---|---|
| **Python 3.11** | 설치.bat이 자동으로 확인합니다 | [python.org](https://www.python.org/downloads/release/python-3119/)에서 **Windows installer (64-bit)**를 받아 실행하세요. 첫 화면에서 **"Add python.exe to PATH"**를 꼭 체크한 뒤 Install Now를 누릅니다. |
| **ffmpeg** | 설치.bat이 자동으로 확인합니다 | 시작 메뉴에서 **명령 프롬프트**를 열고 `winget install Gyan.FFmpeg`를 입력한 뒤 Enter를 누릅니다. 끝나면 명령 프롬프트를 닫습니다. |

### 1-2. 설치.bat 실행

1. 이 폴더의 **`설치.bat`**을 더블클릭합니다.
2. 검은 창에서 `[1/5]` ~ `[5/5]`가 차례로 진행됩니다.
   - 처음 설치할 때는 음성인식 모델(약 1.6GB)을 내려받아서 **5~15분** 정도 걸립니다.
3. 마지막에 **"컴퓨터를 켤 때 서버가 자동으로 켜지게 할까요?"**라고 물으면
   - `Y`: 컴퓨터를 켤 때마다 자동으로 준비됩니다. 브라우저에서 주소만 열면 바로 쓸 수 있습니다. **권장**
   - `N`: 쓸 때마다 `실행.bat`을 더블클릭합니다.
4. 아무 키나 눌러 창을 닫습니다.

> `[오류]`가 나오면 창에 적힌 안내를 따르면 됩니다. 해결이 안 되면 창을 캡처해서 담당자에게 보내주세요.

---

## 2. 매번: 실행하기

- **자동 실행을 켰다면:** 브라우저(크롬 권장) 주소창에 **http://localhost:8000**을 입력합니다. 즐겨찾기에 추가해 두면 편합니다.
- **자동 실행을 안 켰다면:** **`실행.bat`**을 더블클릭하면 잠시 뒤 브라우저가 자동으로 열립니다.

프로그램은 창 없이 뒤에서 실행됩니다. 브라우저 탭을 닫아도 계속 켜져 있고, 분석이나 내보내기도 멈추지 않습니다.
완전히 끄고 싶으면 **`종료.bat`**을 더블클릭하세요.

## 3. 사용 순서

### ① 영상 올리기
1. 첫 화면의 **새 프로젝트** 칸에 영상 파일을 끌어다 놓거나, 클릭해서 고릅니다. mp4, mov, m4v 파일을 여러 개 고를 수 있습니다.
2. 여러 개를 올리면 **파일 이름 순서대로** 이어붙여집니다. ▲▼ 버튼으로 순서를 바꿀 수 있습니다. (편집 화면에서도 나중에 다시 바꿀 수 있습니다.)
3. **업로드하고 분석 시작**을 누릅니다.

### ② 자동 분석 기다리기
진행 상황이 화면에 표시됩니다. 10분 영상 기준으로 걸리는 시간은 다음과 같습니다.

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 무음 구간 분석 | 조용한 부분을 찾아 컷 후보를 만듭니다 | 수 초 |
| 미리보기 영상 | 편집 화면에서 볼 가벼운 영상을 만듭니다 | 약 1분 |
| 음성인식 | 말소리를 글자로 바꿔 자막을 만듭니다 | 약 4~5분 |

창을 닫아도 분석은 계속됩니다. 나중에 첫 화면의 **이전 프로젝트 이어하기**에서 다시 열면 됩니다.

### ③ 편집 화면에서 확인하고 고치기

```
┌──────────────────────────────┬─────────────────┐
│                              │ 편집 / 무음 설정 │
│        영상 미리보기           │   / 자막 스타일   │
│      (자막이 겹쳐 보임)        │                 │
│                              │  확인 필요 목록   │
├──────────────────────────────┴─────────────────┤
│ 클립    [1. 파일A        ][2. 파일B       ]      │
│ 음성·컷  ∿∿∿[▨▨]∿∿∿∿[┄┄┄┄]∿∿∿∿∿[▨]∿∿∿            │
│ 자막    [안녕하세요][오늘은][...]                  │
└────────────────────────────────────────────────┘
```

**컷(잘라낼 부분)**
- **빨간 빗금**은 잘라낼 구간입니다. **노란 점선**은 "말이 없는 것 같은" 제안인데, 아직 적용되지 않은 상태입니다.
- 양쪽 끝을 **드래그**하면 범위가 바뀝니다.
- **더블클릭**하면 적용과 해제가 바뀝니다. 선택한 뒤 **Delete** 키를 누르면 지워집니다.
- 파형의 빈 곳을 **드래그**하면 새 컷이 생깁니다.
- 영상 아래의 **"컷 적용해서 보기"**를 켜 두면, 잘릴 부분을 건너뛰며 재생되어 결과물을 미리 볼 수 있습니다.

**자막**
- 자막 블록을 **클릭**하면 오른쪽 패널에서 글자와 시작·끝 시간을 고칠 수 있습니다.
- 블록을 **드래그**하면 위치가 옮겨지고, 양쪽 끝을 드래그하면 길이가 바뀝니다.
- 자막 줄의 빈 곳을 **더블클릭**하면 새 자막이 추가됩니다.
- 오른쪽 **자막 스타일** 탭에서 글자 크기, 색, 외곽선, 위치(하단/상단)를 바꿉니다. 미리보기에 바로 반영됩니다.

**⚠ "확인 필요" 표시**
- 자동 판단이 불확실한 곳입니다. 오른쪽 **편집** 탭의 목록을 클릭하면 그 위치로 이동합니다.
- 확인한 뒤 **확인 완료**를 누르면 표시가 사라집니다.
- **표시가 없는 자막도 틀릴 수 있습니다.** 특히 이름, 숫자, 전문용어, 마스크를 쓰거나 작게 말한 부분이 그렇습니다. 내보내기 전에 한 번 훑어보세요.

**클립 순서 바꾸기 · 그룹**
- 하단 타임라인의 **클립 줄**에서 클립을 **끌어서** 순서를 바꿀 수 있습니다. 노란 세로선이 놓일 위치를 보여줍니다.
- 순서를 바꾸면 그 클립에 있던 **컷과 자막도 함께 따라갑니다.** 순서가 바뀌면 미리보기 영상을 다시 만드느라 잠깐(10분 영상 기준 약 1분) 편집 화면을 벗어났다가 자동으로 돌아옵니다.
- 클립을 **Ctrl(또는 Shift)+클릭**으로 여러 개 고르면 툴바에 **🔗 그룹으로 묶기**가 나타납니다. 그룹은 항상 붙어서 이동합니다(예: "거실" 클립 3개를 하나로 묶어 통째로 옮기기). 그룹 이름표를 **더블클릭**하면 이름을 바꿀 수 있습니다.
- **그룹 풀기**로 묶음을 해제할 수 있습니다.

**그 밖에**
- 고친 내용은 **자동으로 저장**됩니다(약 1초 뒤). 화면 위쪽에 "임시저장됨 HH:MM"이 표시됩니다.
- 상단의 **💾 임시저장** 버튼을 누르면 그 자리에서 바로 저장됩니다. 확실하게 저장해 두고 싶을 때 누르세요.
- **되돌리기**는 Ctrl+Z, **다시하기**는 Ctrl+Shift+Z입니다.
- 무음이 너무 많이 또는 너무 적게 잘리면 **무음 설정** 탭에서 값을 바꾸고 **다시 감지**를 누르세요. 직접 고친 컷과 자막은 그대로 유지됩니다.

| 단축키 | 동작 |
|---|---|
| Space | 재생 / 정지 |
| ← / → | 1초 뒤로 / 앞으로 (Shift를 함께 누르면 1프레임) |
| Delete | 선택한 컷·자막 삭제 |
| Ctrl + Z / Ctrl + Shift + Z | 되돌리기 / 다시하기 |
| Ctrl + 마우스 휠 | 타임라인 확대 / 축소 |
| Esc | 선택 해제 |

### ④ 작업 이어하기 (임시저장)

- 언제든 브라우저 탭을 닫거나 컴퓨터를 꺼도 편집 내용은 남아 있습니다.
- 첫 화면의 **💾 작업 중 (임시저장)** 목록에서 프로젝트를 클릭하면 하던 자리에서 이어서 편집할 수 있습니다.

### ⑤ 내보내기 (미리 확인용) vs 완료 (최종)

편집 화면 오른쪽 위에 버튼 두 개가 있습니다. 용도가 다릅니다.

| 버튼 | 용도 | 편집 내용 |
|---|---|---|
| **내보내기** | 지금까지 편집한 결과를 mp4로 한 번 뽑아 확인해 보고 싶을 때 | 그대로 유지됩니다. 계속 고칠 수 있습니다. |
| **✔ 완료** | 편집이 다 끝났을 때, 최종 결과물을 만들고 작업을 마무리 | **작업 기록과 업로드 사본이 삭제됩니다.** 이후 이 프로그램에서 다시 수정할 수 없습니다. |

**내보내기** (작업 유지)
1. **내보내기** 버튼 → 옵션 선택 → **내보내기 시작**.
   - **자막을 영상에 입히기:** 자막이 영상 화면에 박힌 mp4를 만듭니다.
   - **SRT 자막 파일도 따로 저장:** 유튜브에 자막 파일로 따로 올릴 때 씁니다.
2. 10분 영상 기준 약 3~12분 걸립니다. 여러 번 눌러도 되고, 이전 결과 목록이 창 안에 남습니다.

**✔ 완료** (최종, 편집 기록 삭제)
1. **✔ 완료** 버튼을 누르면 내려받을 **형식**을 하나 이상 고릅니다.

   | 형식 | 내용 | 이럴 때 |
   |---|---|---|
   | **완성 영상 (자막 입힘)** | mp4 1개, 자막이 화면에 박혀 있음 | 바로 유튜브 업로드 |
   | **자막 없는 영상 + SRT** | mp4 + srt 파일 | 유튜브에 자막을 따로 올리거나, 캡컷에서 영상을 불러온 뒤 자막만 SRT로 얹을 때 |
   | **프리미어 · 다빈치용** | XML(시퀀스) + 원본 클립 사본 + SRT | 프리미어 프로나 다빈치 리졸브로 옮겨서 추가 편집할 때. 컷으로 잘린 구간이 클립 조각으로 나뉜 채로 열립니다. |
2. 안내문을 읽고 **삭제에 동의**하는 체크박스를 켠 뒤 **완료하고 파일 만들기**를 누릅니다.
3. 다 만들어지면 파일별 **⬇ 내려받기** 링크가 뜨고, 이 작업은 첫 화면의 **✔ 완료** 목록으로 옮겨집니다. 완료 목록에서 언제든 다시 열어 파일을 내려받을 수 있지만, **편집은 다시 할 수 없습니다.**

> **프리미어/다빈치용 XML 사용법:** 결과 폴더를 통째로 복사하거나 그 자리에 두고, 프리미어에서 **파일 > 가져오기**로 `..._프리미어_다빈치.xml`을 엽니다. `media` 폴더 안의 원본 클립을 XML이 상대 위치로 가리키므로, XML과 `media` 폴더를 항상 같은 폴더에 두세요. 자막은 XML에 포함되지 않으니 같은 폴더의 `.srt`를 프리미어의 **캡션 가져오기**로 따로 불러오세요.

결과는 이 폴더 안의 **`output`** 폴더에 저장됩니다. 같은 이름이 있으면 덮어쓰지 않고 새 이름(폴더)으로 만듭니다.

## 4. 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| http://localhost:8000 이 안 열림 | `실행.bat`을 더블클릭하세요. 그래도 안 되면 `종료.bat` → `실행.bat` 순서로 다시 켜 보세요. |
| "ffmpeg을 찾을 수 없습니다" | 1-1의 ffmpeg 설치를 다시 하고, 컴퓨터를 한 번 재시작하세요. |
| 분석이 "실패/중단"으로 나옴 | 프로젝트를 열면 두 가지 버튼이 보입니다. 편집하던 컷·자막이 있다면 **"미리보기만 다시 만들기"**를 먼저 눌러보세요(편집 내용이 그대로 유지됩니다). 그래도 안 되거나 처음 분석부터 실패했다면 **"처음부터 다시 분석"**을 누르세요(편집 내용이 사라집니다). |
| 클립 순서를 바꾼 뒤 미리보기가 안 뜸 | 순서를 바꾸면 미리보기 영상을 다시 만드는데, 이 도중 창을 닫으면 "실패"로 표시될 수 있습니다. 위 항목대로 **"미리보기만 다시 만들기"**를 누르면 편집 내용은 그대로 복구됩니다. |
| 자막 시작·끝이 조금씩 어긋남 | 자동 인식 시간은 0.1~0.3초 정도 오차가 있을 수 있습니다. 블록 끝을 드래그해 맞추세요. |
| 컷이 말을 잘라먹음 | **무음 설정**에서 "말 앞뒤 여유"를 늘리고(예: 0.25초) 다시 감지하세요. |
| 조용한 부분이 안 잘림 | 노란 점선 제안을 더블클릭해 적용하거나, **무음 설정**에서 "최소 무음 길이"를 줄여 보세요. |
| 이 폴더를 다른 곳으로 옮김 | `.venv` 폴더를 지우고 `설치.bat`을 다시 실행하세요. 자동 실행을 쓰고 있었다면 `자동실행_켜기.bat`도 다시 실행하세요. |
| 기록을 보고 싶음 | `workspace\server.log` 파일에 프로그램 기록이 남습니다. 문의할 때 함께 보내주세요. |

**자동 실행 켜기/끄기:** `자동실행_켜기.bat` / `자동실행_끄기.bat`을 실행하면 됩니다. 윈도우 "시작프로그램" 폴더에 바로가기 하나를 만들거나 지우는 방식입니다.

## 5. 알아두면 좋은 점

- **디스크 공간:** 프로젝트마다 `workspace\projects\` 안에 영상 사본과 미리보기 영상이 쌓입니다. 원본 영상 크기 + 10분당 약 160MB입니다. **✔ 완료**를 누르면 이 사본과 편집 기록이 자동으로 지워지므로, 다 쓴 작업은 완료 처리하는 것만으로 디스크 공간이 정리됩니다. 완료하지 않고 그만둔 작업은 첫 화면 "작업 중" 목록에 계속 남으니, 필요 없으면 `workspace\projects\<날짜-시간 폴더>`를 직접 지워도 됩니다(결과물은 `output` 폴더에 따로 있으니 영향 없습니다).
- **결과 영상:** H.264, 30fps로 원본 해상도 그대로 나옵니다. 1080p 10분이면 약 550MB입니다. 60fps로 촬영한 영상도 30fps로 나옵니다.
- **자막 글꼴:** 맑은 고딕(Windows 기본)을 씁니다.
- **언어:** 한국어 음성 기준입니다.
- **여러 클립:** 클립마다 해상도가 다르면 첫 번째 클립 크기에 맞추고, 남는 부분은 검은 여백으로 채웁니다.

## 폴더 구성 (참고)

```
영상편집/
├── 설치.bat / 실행.bat / 종료.bat / 자동실행_켜기.bat / 자동실행_끄기.bat
├── output/            ← 완성된 영상·자막 (여기서 가져가세요)
├── workspace/         ← 작업용 사본, 미리보기, 편집 기록 (자동 관리)
├── models/            ← 음성인식 모델 (약 1.6GB)
├── backend/           ← 프로그램 (서버, 무음 감지, 음성인식, 내보내기)
├── frontend/          ← 편집 화면
├── tests/             ← 동작 검사 (.venv\Scripts\python -m unittest discover tests)
└── requirements.txt
```

사용한 오픈소스: ffmpeg(영상 처리), faster-whisper + Whisper large-v3-turbo(음성인식), FastAPI(로컬 서버), React(편집 화면).
